Using Shinpo

The app uses native Apple controls, accessibility labels and support for larger text. Try VoiceOver and iOS display settings. These public pages use text headings, language and reading-direction information, keyboard-accessible links and responsive layouts. Browser zoom is supported.

Status and limitations

A comprehensive independent accessibility audit has not been completed; no full certification is claimed. Dense screens, charts, color combinations and very large text layouts require further assessment. This statement does not claim an exemption from applicable accessibility duties.

Report a barrier

Email shinpo.kai22@gmail.com with the screen or page, intended action, device, operating system and assistive technology, if relevant. Do not include private task content unless necessary. We will assess the barrier and provide reasonable assistance where possible. You can request information in an accessible format or help with a privacy request through the same address.
